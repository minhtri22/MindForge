# PIT-9 — Candidate Teacher Qualification

Status: Research Planning

## Purpose

Define the qualification process for candidate PIT teacher strategies using the PIT-8 evaluation protocol.

PIT-9 does not select a final teacher model. It evaluates candidate suitability before any implementation, training, or integration decision.

## Qualification Dimensions

Candidates are evaluated against:

- pattern understanding
- temporal reasoning
- correction capability
- uncertainty handling
- supervision quality
- personalization safety

## Evaluation Output

Each candidate produces:

- capability profile
- strengths
- weaknesses
- failure modes
- qualification verdict

Possible verdicts:

- QUALIFIED
- QUALIFIED_WITH_LIMITS
- NOT_SUITABLE

## Constraints

No model selection.

No training.

No MindForge runtime changes.

No PPF changes.

No production integration.

## Next Step

Apply the frozen PIT-8 protocol to candidate teacher strategies.
