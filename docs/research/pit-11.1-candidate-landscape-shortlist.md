# PIT-11.1 — Candidate Landscape and Shortlist

Status: Research Definition

## Purpose

Define the candidate landscape before executing PIT-11 teacher qualification.

PIT-11.1 does not select a final teacher model. It creates a shortlist for evaluation using the frozen PIT-10 contract.

## Evaluation Boundary

Candidates are evaluated for Personal Intelligence Teacher suitability, not general benchmark ranking.

Required capabilities:

- evidence grounded pattern discovery
- uncertainty awareness
- pattern lifecycle management
- correction recovery
- teaching signal generation

## Candidate Categories

### General Frontier Models

Examples:

- GPT class models
- Claude class models
- Qwen class models

Potential strengths:

- reasoning
- language understanding
- broad knowledge

Evaluation focus:

Ability to transform general intelligence into personal teaching signals.

### Memory-Centric Systems

Focus:

- personal memory grounding
- user history representation
- evidence tracking

Risk:

Memory retrieval alone may not provide reasoning or pattern evolution.

### Reflection-Centric Systems

Focus:

- reflection loops
- hypothesis generation
- outcome interpretation

Risk:

Requires reliable evaluation and correction mechanisms.

### Hybrid Systems

Focus:

- memory grounding
- reflection
- uncertainty
- lifecycle management

## Shortlist Criteria

A candidate may proceed only if it can be evaluated against:

- observation/inference separation
- confidence estimation
- applicability boundaries
- revision triggers
- pattern lifecycle quality

## Decision Boundary

PIT-11.1 does not:

- choose a winner
- download models
- train models
- modify MindForge
- modify PPF

## Next Step

PIT-11 candidate execution under the frozen evaluation contract.
