# OIR-PPV Research Archive

This directory is the local archive/index for historical research documents that are outside the active v1.0 source-of-truth set.

Canonical active documents live under:

- `ontology/`;
- `formal/`;
- `protocols/`;
- `governance/`.

Historical H3 evidence remains in its original experiment/artifact locations and is indexed by `protocols/h3/historical/README.md`. It is not copied or rewritten here.

The prior `docs/` staging directory still contains non-authoritative pre-FIX/reviewer material. Those files are retained for provenance and are not active source of truth.
