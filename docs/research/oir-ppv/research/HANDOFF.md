# OIR-PPV Developer to PM/QA Handoff Protocol

## Required handoff package

Every development milestone must provide:

1. Implementation summary
2. Changed files
3. Commit SHA
4. Experiment command
5. Runtime environment
6. Generated artifacts
7. Known limitations
8. Developer self-check result

## QA process

PM/QA will:

1. Verify source changes against milestone scope.
2. Reproduce required commands.
3. Validate artifacts and provenance.
4. Record acceptance or rejection.
5. Update milestone status.

## Artifact registry

Each milestone maintains:

- code changes
- configuration
- datasets
- seeds
- logs
- metrics
- reports

No milestone is considered complete without evidence.
