# Reconstruction Archive

Contains the complete OIR-PPV simulator evolution from v0.11 (proxy for v0.1) through v0.13.10.

Each version directory contains:
- `simulator.py` - The simulator implementation
- `config.json` - Configuration (where available)
- `README.md` - Version-specific notes

## Version Progression

v0.11 → v0.12 → v0.13 → v0.13.1 → ... → v0.13.10

The v0.11 version serves as the v0.1 baseline since the original v0.1 was not preserved separately.
