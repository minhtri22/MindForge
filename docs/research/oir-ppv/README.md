## Definition

OIR-PPV (Obvious-In-Retrospect Innovation — Pattern Persistence Value) studies discovery, validation and preservation of minimal generative invariants from experience.

Core loop:

```
Observe
 -> Compress
 -> Discover invariant
 -> Validate causally
 -> Predict novel manifestation
 -> Experiment
 -> Update
```

## Scope

OIR-PPV does not claim general intelligence or universal causal discovery. It studies compact transferable generative invariants.
