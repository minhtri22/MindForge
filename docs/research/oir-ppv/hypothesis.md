# OIR-PPV Frozen Hypothesis

## Main hypothesis

A system can transform experience into compact latent invariants that:

1. explain observed manifestations;
2. survive causal validation;
3. transfer across environments;
4. generate novel valid manifestations.

## Invariant

A latent causal principle that maintains effect across contexts, interventions and manifestations.

Required properties:

- causal
- transferable
- generative
- minimal

## Generator

A minimal mechanism that maps an invariant into multiple concrete manifestations.

## Validation ladder

1. Observation
2. Intervention
3. Counterfactual validation
4. Generative validation

## Experiment

An action selected to reduce uncertainty between competing hypotheses.
