# OIR-PPV v0.13.11 — Historical Failure Replay

## Purpose

Replay the original adversarial failure classes from v0.11 against the frozen v0.13.10 architecture.

This experiment is a regression gate:

> Does the final architecture actually fix the failures that motivated its evolution?

## Important provenance note

The original interactive sanity runs were not persisted as executable artifacts. Therefore this experiment reconstructs the failure classes and freezes them as reproducible seeds.

Seed registry in `artifacts/seeds/v0.13.11_seed_registry.json` is the source of truth for replay.

## Comparison

Baseline:

- OIR-PPV v0.11 architecture
- reward/frequency/transfer scoring

Treatment:

- OIR-PPV v0.13.10 architecture
- causal validation
- minimal generative invariant
- hypothesis experiment loop

## Acceptance

The treatment must:

1. recover rare structural invariants
2. reject reward-only shortcuts
3. compress manifestations into generators
4. preserve reproducibility with frozen seeds
