# CLRM-0 — Eligible Population Contract

Status: **FROZEN**

## Unit

The scientific unit is one canonical pre-boundary state from a fresh seed
trajectory under the unchanged current KCL-compatible four-task substrate.

Eligible boundaries are exactly:

```text
after T1 → T2
after T2 → T3
after T3 → T4
```

Each eligible boundary must support matched A/B/C forks from the exact same
pre-boundary model, optimizer, memory and data state.

## All-boundary principle

The primary population is:

```text
ALL prospectively eligible matched boundaries
```

Eligibility must be determined before post-policy outcomes are inspected.

It may not depend on:

- hard action labels;
- response magnitude;
- contrast sign;
- terminal accuracy;
- terminal loss;
- proximity to a threshold;
- whether any policy appears beneficial.

## Seed grouping

Seed is the independence/grouping unit.

All three boundaries from one seed remain together in any support,
development, validation, or replication role.

No boundary-row split across roles is permitted.

## Substrate scope

CLRM-0 retains the same current substrate resolved by MSA.

Difficulty mutation is not authorized.

A different substrate/task family requires a separate independently justified
program or a formal convergence transition.
