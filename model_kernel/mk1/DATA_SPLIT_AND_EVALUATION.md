# MK-1 Data Split, Evaluation and Falsification Contract v0.1

Status: **FROZEN SPECIFICATION / NO DATA MATERIALIZED**

Date: **2026-09-21**

## 1. Split principle

MK-1 measures generalization across semantic-scene and surface-form novelty.

All variants of one canonical semantic scene remain in exactly one split.

No surface template, canonical scene ID, or paraphrase cluster may cross split boundaries.

## 2. Reserved generation namespaces

The implementation must reserve these disjoint namespaces:

- TRAIN: `7101000..7102999` — 2,000 canonical scenes;
- VALIDATION: `7103000..7103399` — 400 canonical scenes;
- PRISTINE_CONFIRMATORY: `7104000..7104599` — 600 canonical scenes.

These identifiers are generation namespaces, not model-training seeds.

If materialization cannot satisfy frozen support/integrity gates from these namespaces, do not silently extend them. Use a documented pre-outcome amendment before training.

## 3. Surface multiplicity

Each canonical scene must have at least two semantics-preserving surface realizations.

At least one realization per confirmatory scene must be generated by a surface-construction route not used for the training realization family.

The exact renderer/provider/toolchain must be implementation-locked before data generation.

## 4. Composition coverage

PRISTINE_CONFIRMATORY must include:

- every primary Z1 family;
- every primary Z3 scope level that remains scientifically admissible after support audit;
- every primary Z4 relation type;
- at least 30% multi-factor scenes containing two or more independently scorable semantic mechanisms.

No class required for primary adjudication may violate TARGET_STABILITY_AUDIT.md support gates.

## 5. Pristine integrity

Before any confirmatory inference, verify:

- exact raw-text duplicate count = 0 against TRAIN/VALIDATION;
- exact canonical-scene duplicate count = 0;
- template-family overlap = 0 for held-out renderer families;
- confirmatory targets were frozen before model predictions;
- confirmatory execution count = 0.

The final confirmatory evaluation is one-shot per frozen checkpoint set.

## 6. Primary representation metrics

Evaluate separately by target family and pooled across eligible fields:

### Z1 primitives
- micro precision;
- micro recall;
- macro F1 across supported primitive classes;
- exact-set match.

### Z2 normalized arguments
- exact accuracy for categorical comparator/unit fields;
- symmetric per-record normalized absolute error for continuous fields:
  `nAE = |prediction-gold| / max(|gold|, 1 canonical unit)`;
- relation/order accuracy.

For a continuous field, define its score as:
`continuous_score = 1 - min(mean_nAE, 1)`.

The Z2 eligible-field score is the unweighted mean of:
- categorical exact accuracy;
- continuous_score when continuous fields are present;
- relation/order accuracy when relation/order fields are present.

Missing field types are omitted rather than imputed.

### Z3 scope
- evidence-scope accuracy;
- asserted-scope accuracy;
- scope-relation accuracy.

### Z4 relations
- edge precision;
- edge recall;
- edge macro F1.

### recomposed state
- canonical-state field accuracy;
- full-state exact match;
- invariance-cluster consistency.

## 7. Frozen absolute gates for M1-Z

M1-Z absolute PASS requires all:

1. Z1 micro precision >= 0.95;
2. Z1 micro recall >= 0.95;
3. Z1 macro F1 >= 0.90;
4. Z3 scope-relation accuracy >= 0.95;
5. Z4 edge precision >= 0.95;
6. Z4 edge recall >= 0.90;
7. recomposed canonical-state field accuracy >= 0.95;
8. invariance-cluster consistency >= 0.95;
9. no supported primary class has recall < 0.80;
10. all target-stability and observable-identifiability gates PASS;
11. for every supported primary continuous Z2 field:
    - mean nAE <= 0.05;
    - 95th percentile nAE <= 0.10.

The nAE definition above is frozen now. No field-specific validation-optimal scaling or thresholding is allowed.

## 8. Paired comparison: M1-Z vs B0-DIRECT

Define a per-scene balanced representation score as the unweighted mean of:

- Z1 macro F1;
- Z2 eligible-field score;
- Z3 scope-relation accuracy;
- Z4 edge macro F1;
- recomposed canonical-state field accuracy.

For each training seed, evaluate both arms on the same confirmatory scenes.

Primary paired improvement gate:

- mean score improvement >= +0.03 absolute;
- 95% whole-scene paired bootstrap lower bound > 0.

If M1-Z passes absolute gates but not this paired gate:

`LEARNED_REPRESENTATION_SUPPORTED_FACTORISATION_NOT_ESTABLISHED`

The simpler direct learned representation remains preferred for later work unless another hypothesis is preregistered.

## 9. Comparison: M1-Z vs D-PIT

Compare only the intersection of fields supported by both contracts.

Require:

- pooled error reduction >= 20% relative to D-PIT;
- whole-scene bootstrap lower 95% bound for relative error reduction >= 10%;
- M1-Z primitive precision must not be lower than D-PIT by more than 0.02 absolute.

If M1-Z passes absolute gates but not the D-PIT improvement gate:

`LEARNED_Z_ABSOLUTE_PASS_NO_DETERMINISTIC_UPLIFT`

No claim of overcoming the deterministic ceiling is allowed.

## 10. Formal verdict matrix

Sequential adjudication:

1. data/split integrity;
2. target stability;
3. observable identifiability;
4. B0 reconstruction and arm matching;
5. M1-Z absolute representation gates;
6. M1-Z vs B0-DIRECT paired gate;
7. M1-Z vs D-PIT improvement gate.

Formal outcomes:

- integrity/target/identifiability failure:
  `MK1_INVALID_BEFORE_TRAINING`
- M1-Z absolute FAIL:
  `LEARNED_STRUCTURED_REPRESENTATION_NOT_SUPPORTED`
- M1-Z absolute PASS, B0 paired FAIL:
  `LEARNED_REPRESENTATION_SUPPORTED_FACTORISATION_NOT_ESTABLISHED`
- M1-Z absolute PASS, B0 paired PASS, D-PIT uplift FAIL:
  `STRUCTURED_FACTORISATION_SUPPORTED_NO_DETERMINISTIC_CEILING_BREAK`
- all gates PASS:
  `MK1_LEARNED_STRUCTURED_REPRESENTATION_SUPPORTED`

## 11. STOP rules

After a valid confirmatory FAIL:

- do not tune thresholds;
- do not replace seeds;
- do not add hidden units;
- do not add a latent arm;
- do not add memory/history/future probes;
- do not merge MK-2 decision loss into MK-1;
- do not regenerate the confirmatory cohort.

A new experiment requires a new uncertainty and a new preregistration.

## 12. MK-2 boundary

MK-1 does not adjudicate whether Z improves final decision quality.

Even a full MK-1 PASS only authorizes designing MK-2 Decision Sufficiency.
